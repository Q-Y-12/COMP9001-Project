# OopsMate: A Social Rescue Message Generator

## Project Description
OopsMate is a terminal-based Python program. It can help users generate short rescue messages for awkward daily situations, such as being late for class, forgetting assignments, missing group meetings etc. However, this program is mainly for fun and creative writing. It is not designed to encourage serious lying.

## How to Run
In terminal, run the program with: python3 Oopsmate.py
And run the test with: python3 OopsmateTest.py, for the test, if all good, it will print "All tests passed".

## Libraries Used
This project only uses Python built-in libraries:
random
os
time
sys
No external libraries are needed. This project does not use GUI, web features, networking, audio, video or graphics libraries.

## Main Features
The user can:
1. choose a situation
2. choose a message style
3. generate a rescue message
4. save messages to favourites
5. add custom message templates
6. view message history
7. view usage statistics

## Message Styles
The messages in the program have four styles:
1. Chaotic: the excuse is ridiculous, random and mainly for fun.
2. Honest: the excuse is polite, sincere, responsible and sounds like a real apology.
3. Confused: the excuse sounds like the user is pretending not to understand what happened and should be short and slightly silly.
4. Let it go: the excuse is lazy, careless and relaxed. People will not explain much and just accept the situation.

## Files Created by the Program
The program may create these text files when it runs:
1. favourites.txt  
2. custom_templates.txt  
3. history.txt
   
These files are used to save favourite messages, custom templates and message history. They do not need to be created manually.
